MODELO DE PERFILES

Perfil Básico:
- gratis por defecto;
- no mostrar "Soy usuario";
- nombre obligatorio;
- sexo obligatorio;
- edad obligatoria;
- teléfono opcional;
- foto de perfil disponible;
- funciones Premium con candado claro.

Perfil Cuidador/a:
- gratuito;
- NO pedir teléfono;
- NO SMS;
- NO verificación telefónica;
- nombre, sexo, edad y foto;
- puede recibir avisos/chat/llamadas de pacientes Premium vinculados;
- no obtiene Premium para sí mismo;
- puede ser Cuidador/a + Premium.

Perfil Premium:
- desbloquea IA real, identificación/explicación completa de medicamentos, voz natural y funciones Premium;
- puede vincular cuidadores;
- IAP debe verificarse en servidor.

VINCULACIÓN CUIDADOR

Cada paciente Premium tiene código fijo de 6 cifras.
El cuidador puede:
A) escribir el código;
B) escanear QR.
QR opcional.
Ambas rutas crean solicitud pendiente.
El paciente debe Aceptar o Rechazar.
Hasta aceptar no se comparten datos.
Después:
"Cuidador/a de [Nombre paciente]".
El paciente puede desvincular con doble confirmación.
El cuidador puede abandonar vínculo con confirmación.
Si pierde el último vínculo y no paga Premium -> Básico.
Si tiene Premium -> sigue Premium.

IA LUCÍA

Debe:
- mantener conversación continua;
- no volver a saludar cada turno;
- preguntar cómo está hoy cuando encaje;
- acompañar con tono amable;
- persistir historial;
- mantener contexto longitudinal;
- mostrar "Pensando..." animado;
- escribir progresivamente la respuesta;
- NO reanimar el historial antiguo;
- responder automáticamente por voz natural a cada nueva respuesta;
- permitir hablar manteniendo pulsado el micrófono y soltar para enviar;
- transcribir y enviar;
- no usar fallback robótico silencioso.

Voces:
- Sulafat;
- Achird;
- Aoede.
Aoede puede usarse como voz más suave/armoniosa para Lucía.
La lectura de medicamentos debe usar Sulafat.

LECTURA DE MEDICAMENTOS

Debe prepararse como reproducción continua.
No cortar palabras entre tarjetas/apartados.
Nunca reproducir "senci-" y luego "llas" en el siguiente bloque.
Controles:
- reproducir;
- pausar;
- continuar;
- repetir desde principio;
- progreso;
- tiempo actual;
- duración;
- iconos claros;
- diseño responsive.
Si Sulafat falla, mostrar error y reintentar; no cambiar a voz robótica.

EMERGENCIA

Dentro del chat de Lucía, cuando detecte posible emergencia, mostrar:
- "Avisar y llamar a mi cuidador/a";
- "Abrir emergencia".

Al pulsar avisar/llamar:
1. crear incidente;
2. notificar cuidador aceptado;
3. abrir chat de emergencia;
4. compartir motivo;
5. compartir ubicación autorizada;
6. iniciar automáticamente llamada VoIP al cuidador;
7. cuidador acepta llamada;
8. mantener chat/ubicación durante incidente.

Solo cuidadores aceptados pueden recibir emergencia.

La llamada debe ser WebRTC/VoIP, no llamada telefónica de pago.
Configurar TURN para producción.
No declarar llamada autónoma real al 112 mientras no esté validada legal/técnicamente.
El 112 permanece manual hasta esa validación.

NOTIFICACIONES

MICRÓFONO

La siguiente build debe incluir NSMicrophoneUsageDescription REAL dentro del Info.plist final.
No basta con app.json.
Descargar IPA y comprobar el plist embebido.
Pulsar micrófono jamás puede cerrar la app.
